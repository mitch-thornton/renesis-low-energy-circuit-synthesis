# Patents

Some results in this repository are covered by U.S. patents pending assigned to
Clearpoint Research, LLC.

The MIT license in `LICENSE` grants copyright permissions for the source code in
this repository. It does not grant any patent rights. The distinction matters in
practice:

- A graduate student or academic **studying** the methods, reading the code, and
  reproducing the results for research or coursework is exercising the copyright
  grant and needs nothing further.
- A researcher **comparing** their own method against this one, or building on it in
  a non-commercial academic setting, is likewise covered by the copyright grant.
- A company **deploying** the methods in a commercial product or service may require
  a separate patent license, independent of the MIT copyright grant.
- Downstream open-source software that incorporates this code still needs a patent
  license for any **commercial deployment** of the patented methods, because the MIT
  license passes along copyright permissions only, not patent rights.

For patent-licensing inquiries, contact Clearpoint Research, LLC.
